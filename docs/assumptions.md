# Допущения MVP

- Только действующие клиенты банка. Регистрации юрлица нет.
- Внешние проверки — моки с тем же смыслом: ЕГРЮЛ, ФНС, БКИ.
- Подписание — код в интерфейсе, не УКЭП и не SMS. В проде это ДБО / Госключ.
- Выдача денег смоделирована статусом `issued`.
- Залога, СБ, кредитного комитета и посткредита нет. What-If «поручительство МСП» — демо-флаг, не реальный залог.
- ИП и ООО идут одним процессом, различается карточка.
- Ставки = ключевая 16.5% + спред от скоринга. Это рыночная модель, не тариф Альфа-Банка.
- LLM, OCR и загрузка документов не входят в проверяемую версию.
- Один веб, две роли, десктоп.
- «Касса» — оборотный экспресс-кредит с аннуитетным графиком, не овердрафт и не возобновляемая линия.
- Суммы округляются до 10 000 ₽. Платёж в месяц: `P * r * (1+r)^n / ((1+r)^n - 1)`, `r = ставка / 12`.
- DSCR = оценка прибыли по ОКВЭД / платёж в месяц. Маржа — упрощённый справочник, не отчётность клиента:

| ОКВЭД | Пример | Маржа |
|-------|--------|-------|
| 10.71 | Пекарня | 12% |
| 41.20 | Стройка | 8% |
| прочие | — | 10% |

- Тумблер «Сбой БКИ» хранится в памяти процесса API. После перезапуска сбрасывается.
- Cure ФНС обнуляет недоимку только в моке реестра этого процесса.
